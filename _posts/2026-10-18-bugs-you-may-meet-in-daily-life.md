爸妈来我家，放了一袋东北秋然大米，结果到夏天，里面生了很多虫子，有米象、印度谷螟（米蛾）。因为我平时不做饭，等9月23日客厅都有谷螟时我才发现，费了半天功夫打扫感觉，米也直接扔了。

然后过了半个多月，到10月17号，我又发现另一袋小米里有米蛾的幼虫。浅黄色蠕动的身体，长得差不多了，会离开食物，到天花板和墙的接缝处吐丝化蛹。这是我第一次直接观察昆虫的习性，虽然有点恶心。

我这里就日常生活可能碰到的虫子做个整理。


| 种类 | 各阶段时间（卵 / 幼虫 / 蛹 / 成虫寿命） | 蛹期 | 关键特点 |
|------|----------------------------------------|------|---------|
| 蚊子 | 2~5天 / 5~14天 / 约2天 / 雌蚊约15~30天，雄蚊约18~20天 | 有 | 卵、幼虫、蛹都在水中；雌蚊吸血，雄蚊吸植物汁液 |
| 苍蝇 | 约1天 / 3~7天 / 3~7天 / 约1个月 | 有 | 节奏最快；蛹为栗褐色硬壳；成虫取食腐烂物和食物 |
| 蠓虫 | 2~7天 / 3~5周 / 5~7天 / 1个月以上 | 有 | 体型仅1~4mm；雌蠓吸血，咬人比蚊子更痒 |
| 印度谷螟 | 3~7天 / 15~25天（温度影响大）/ 7~14天 / 平均约8天 | 有 | 幼虫吐丝结网取食粮食；老熟后离粮到缝隙化薄丝网化蛹；成虫口器退化不取食 |
| 米象 | 约3天 / 约18天 / 约6天 / 约86~230天 | 有 | 卵、幼虫、蛹全在单粒米内完成，最隐蔽；成虫取食谷粒 |
| 蚕宝宝 | 7~10天 / 20~30天 / 10~15天 / 约4~10天 | 有 | 五龄老熟后连续吐丝数十小时，结厚实密闭茧壳；成虫口器退化不取食 |
| 蚂蚁 | 约10~14天 / 约9~15天 / 约14~16天 / 工蚁数周至3~10年；蚁后数年至十年（因种类和阶级差异大） | 有 | 完全变态；社会性昆虫，工蚁照顾幼虫和蛹，常搬动蛹调节温度 |
| 蜜蜂 | 约3天 / 约6~7天 / 工蜂约11~12天，蜂王约7天，雄蜂约14天 / 工蜂生产季约30天；蜂王3~5年；雄蜂约54天 | 有 | 完全变态；社会性昆虫，三型蜂发育时间不同 |
| 蟑螂 | 20~90天 / 30~450天 / 无 / 一般约2年，短约200天 | **无** | 不完全变态；雌虫携带卵鞘护卵；若虫似成虫仅无翅 |
| 蜘蛛 | 8~19天 / 数周至数月 / 无 / 因种类差异极大（小型蛛数月，大型捕鸟蛛雌性可达十余年） | **无** | 非昆虫，8足；卵囊内先蜕皮再分散；捕食性 |

**表下注释**：

1. 蚊子成虫寿命数据参考台湾CDC资料，白线斑蚊约20天，埃及斑蚊可达30天。
2. 苍蝇成虫寿命约1个月；蠓虫成虫可存活1个月以上。
3. 印度谷螟成虫平均寿命约8天。
4. 米象成虫寿命约86~230天；另有资料称7个月到2年，因温度、食物条件浮动较大。
5. 蚕蛾成虫寿命约4~10天，交配产卵后即死亡。
6. 蚂蚁寿命因阶级差异极大：工蚁数周至3~10年，蚁后数年至十年。
7. 蜜蜂三型寿命不同：工蜂生产季约30天，越冬期可长达4~6个月；蜂王3~5年；雄蜂繁殖季约54天。
8. 蟑螂寿命一般约2年，短的约200天。
9. 蜘蛛成虫寿命因种类差异极大，表中未取单一数值；小型居家蜘蛛通常数月，大型种类雌性可活多年。
10. 各阶段时间及成虫寿命因种类、温度、食物条件不同会有浮动，表中为常见参考范围。
